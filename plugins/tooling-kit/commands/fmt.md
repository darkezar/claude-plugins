# Fmt

Отформатируй код.

1. Определи команду по скиллу `detect-tooling`.
2. **По умолчанию форматируй только изменённые файлы**, а не весь проект: массовое
   переформатирование чужого кода создаёт нечитаемый дифф и конфликты при мерже.
   Список бери из `git diff --name-only` и `git diff --cached --name-only`.
3. Аргумент `check` — только проверить, ничего не меняя (`--test`, `--dry-run`, `fmt-check`).
4. Аргумент `all` — форматировать весь проект. Перед этим предупреди, сколько файлов
   затронет, и дождись подтверждения.

После форматирования покажи `git diff --stat`, чтобы объём правки был виден сразу.

## Отчёт

- Что запускалось и к каким файлам применялось.
- Сколько файлов изменено.
- Если форматтер не настроен — так и скажи, не подставляй свой.
