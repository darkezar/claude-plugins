# Приватные артефакты ревью

Для `CI_FILE`, `REQUEST_FILE`, `REPORT_FILE`, `SNAPSHOT_FILE` и временной копии карты ответов
создай отдельный каталог вне проекта через `mktemp -d` / `tempfile.mkdtemp()` (права 0700).
Имена файлов внутри него можно назначить заранее; файлы создавай с правами 0600.
Не используй предсказуемый путь прямо в общем `/tmp` и не следуй симлинкам.
Python-помощники используют `review_storage.py`: проверка владельца/прав и атомарная запись.

Для снимка Codex используй `review_snapshot.py capture ... --output "$SNAPSHOT_FILE"`.
Подготовь полный JSON отчёта как **данные**, в собственном `REPORT_INPUT` 0600 внутри
приватного каталога. Запиши итог без выполнения Python-фрагмента из каталога проекта:

```bash
python3 -I "$PLUGIN_ROOT/scripts/review_storage.py" write --output "$REPORT_FILE" < "$REPORT_INPUT"
```

Подставь сохранённые абсолютные пути в этом же вызове. CLI использует `write_json`,
создаёт файл 0600 атомарно независимо от umask и принимает только JSON из stdin.
`-I` исключает cwd/PYTHONPATH из импорта. Служебные скрипты бери из доверенного установленного
пакета, а не из ветки проверяемого PR. Для иных служебных Python heredoc/`-c` используй
`python3 -I` из приватного каталога артефактов; добавление пути пакета в `sys.path` само по
себе не исключает подмену stdlib из cwd. Для существующего файла с лишними правами
не ослабляй проверку чтения: пересоздай только собственный временный артефакт безопасным CLI.

Для навыка корень пакета — два уровня выше Base directory (`skills/<имя>` или
`codex-skills/<имя>`). В тексте Claude-команды используй подставляемый загрузчиком
`${CLAUDE_PLUGIN_ROOT}`; у команды нет Base directory. Read произвольного справочника
эту подстановку не выполняет: передавай в него уже полученные абсолютные значения.
Запомни пути артефактов в контексте задачи и подставляй литералами в каждый вызов инструмента;
переменные между вызовами Bash не сохраняются. Не создавай заново каталог вместо поиска отчёта.

Долговечная карта PR сохраняется через `scripts/reply_map.py`, см.
[процедуру ответов](fix-review-threads.md); временный каталог не заменяет это хранилище.
Полные логи остаются артефактами, в контекст передавай статус, существенные ошибки и путь.
После работы убери свои временные файлы, если они больше не нужны; ожидающие ответы сохраняй.
