# Команды проверок

Команды картриджей — примеры. Возьми реальные команды из инструкций проекта,
Makefile/justfile, package/composer scripts, CI и настроек тестов. Прочитай тело скрипта,
подтверди бинарь, пакетный менеджер, рабочий каталог и контейнеры. Используй `detect-tooling`,
если он доступен. Не устанавливай зависимости автоматически, включая запуск `npx` без бинаря.
Для ревью запускай проверяющие формы без форматирования, автофиксов и миграций.
Недоступная среда означает «не запускалось» с причиной. Картридж не разрешает правки и отправку.
