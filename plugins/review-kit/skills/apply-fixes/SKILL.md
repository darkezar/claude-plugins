  при существенной неоднозначности. Отвечает на все исправленные inline-комментарии PR

Прочитай [область, выбор решения и проверки](../../references/fix-scope.md), а для PR —
[доверие источнику, ответы и resolve](../../references/fix-review-threads.md).
Нужен готовый отчёт/указанный PR и запрос исправлять; новое ревью команда не проводит.

Определи абсолютный `PLUGIN_ROOT` по каталогу вызванного навыка (два уровня вверх).
При делегации передай **абсолютные пути** `PLUGIN_ROOT/references/fix-scope.md` и
`PLUGIN_ROOT/references/fix-review-threads.md`, потребуй прочитать их до правок.
Относительные ссылки тела агента не задают его рабочий каталог и не заменяют эти пути.

1. Проверь инструкции, ветку/коммит и дерево относительно отчёта; сохрани чужие правки/индекс.
   Свяжи полный список с актуальным кодом и всеми comment ID по общим справочникам.
2. Выбери исполнение по [execution-routing.md](../../references/execution-routing.md).
   Запусти одного `agent-fixer` последовательно, передав всю однозначную партию,
   выбранные решения, worktree/SHA, правила, картриджи, проверки и comment ID.
   `model` и `effort` передавай параметрами Agent tool при каждом запуске; если схема их
   поддерживает, без них fixer не запускай. Делишь партию на пачки — выбирай для каждой отдельно: механика —
   Sonnet/`medium`, деньги, права, миграции и конкурентность — Opus/`high`.
   Если делегация запрещена/недоступна, выполни ту же задачу сам по общей политике исполнения.
   Для локализации в пределах замечаний используй `i18n-sync`.
3. Недостающий неоднозначный выбор получай из основной сессии по `fix-scope`;
   передай ответ fixer. Публикациями управляет координатор.
4. Проверь полный diff и результаты назначенных проверок по `fix-scope`.
5. Выполни [ответы в PR и resolve](../../references/fix-review-threads.md), сверив `reply_map`.

В результате укажи статусы каждого пункта по `fix-scope`, файлы, проверки/ограничения,
исполнение, worktree, карту и итоги ответов/обсуждений. Коммит/push требуют своего основания;
после разрешённой публикации заверши ожидающие обсуждения. Исправления не заменяют
повторную проверку затронутого кода по `agent-full-review`.
