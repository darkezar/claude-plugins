  Полное код-ревью изменений текущей ветки одним агентом: качество кода, паттерны языка
  и фреймворка, типизация, архитектура, обработка ошибок, тесты, прогон линтера и типов.
  Чек-лист адаптируется под стек проекта.
disable-model-invocation: true
---

Проведи полное код-ревью изменений текущей ветки.

1. Определи базовую ветку и активные стеки проекта по скиллу `detect-stack`.
2. Запусти агента **agent-branch-reviewer** через Agent tool, передав в промпте:
   - `BASE_BRANCH` и `BASE` (хеш merge-base);
   - имена картриджей стека (например `stack-laravel`, `stack-expo-rn`);
   - строку: «Одиночный прогон: кроме тебя ревьюеры не запускались. Покрой добором зоны
     performance, auth и design — только явные и грубые проблемы, с пометкой добора».
3. Верни полный отчёт агента пользователю как есть.
