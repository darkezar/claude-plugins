# Быстрое ревью

Выполни [процедуру одиночного ревью](../references/single-review.md).
Это лёгкая проверка одним проходом, без запуска `agent-full-review` и подагентов.

Прочитай разделы «Шаг 4. Чек-лист» и «Формат вывода» общей
[команды review](../../commands/review.md). Применяй только относящиеся к изменению пункты,
с учётом реальных контрактов проекта и выбранных картриджей. Подготовку, Claude-вызовы
и разрешения из общей команды замещает процедура Codex выше.

Сохрани охват пяти зон исходной команды: корректность, безопасность, доступ,
производительность и дизайн-система при наличии UI. Не выдавай малую глубину за полный
аудит. Верни находки CRITICAL / WARNING / SUGGESTION, результаты проверок, ограничения
и оценку готовности с оговоркой об одном проходе.
