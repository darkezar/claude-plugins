# Картридж Laravel для Codex

Подтверди стек по файлам приложения (laravel/framework в composer.json и artisan), версию возьми из манифеста.
Прочитай [общий картридж Laravel](../../skills/stack-laravel/SKILL.md):
чек-листы и триггеры общие с Claude Code. Применяй только подходящие для версии
и конфигурации пункты, соблюдая явные контракты проекта.

Команды раздела «Тулинг» — примеры. Подтверди скрипт, локальный бинарь, пакетный менеджер,
рабочий каталог и контейнеры по проекту; не устанавливай пакеты через npx автоматически.
Для ревью используй проверяющие формы без автофиксов и миграций. Картридж сам по себе
не запускает аудит всего проекта, не разрешает правки, commit, push или публикацию.
