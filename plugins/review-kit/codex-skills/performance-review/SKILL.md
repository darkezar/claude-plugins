# Производительность

Выполни [процедуру одиночного ревью](../references/single-review.md).
Общий предметный чек-лист — [Производительность](../../agents/agent-performance-reviewer.md).
Читай границы зоны, принципы и пункты проверки; Claude-конфигурация и оркестрация
из справочника не выполняются. Отчёт относится только к этой зоне.

Проверь производительность затронутого кода. Остальные ревьюеры не запускались.
Подтверждай стоимость конкретным путём исполнения; не выдавай предположение за измерение.
