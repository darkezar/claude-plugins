# Упрощение

Выполни [процедуру одиночного ревью](../references/single-review.md).
Общий предметный чек-лист — [Упрощение](../../agents/agent-simplify.md).
Читай границы зоны, принципы и пункты проверки; Claude-конфигурация и оркестрация
из справочника не выполняются. Отчёт относится только к этой зоне.

Проверь сложность и дублирование. Остальные ревьюеры не запускались.
Не превращай предложения по качеству в блокирующие баги и не ищи отдельный аудит
безопасности вместо упрощения. Код и поведение без команды пользователя не меняй.
