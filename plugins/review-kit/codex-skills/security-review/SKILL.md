# Безопасность

Выполни [процедуру одиночного ревью](../references/single-review.md).
Общий предметный чек-лист — [Безопасность](../../agents/agent-security-reviewer.md).
Читай границы зоны, принципы и пункты проверки; Claude-конфигурация и оркестрация
из справочника не выполняются. Отчёт относится только к этой зоне.

Выполни одиночный аудит безопасности. Auth-ревьюер отдельно не запускался:
покрой добором IDOR, защиту эндпоинтов, хранение токенов и rate-limit аутентификации.
