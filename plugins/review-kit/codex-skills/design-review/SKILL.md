# Дизайн-система

Выполни [процедуру одиночного ревью](../references/single-review.md).
Общий предметный чек-лист — [Дизайн-система](../../agents/agent-design-reviewer.md).
Читай границы зоны, принципы и пункты проверки; Claude-конфигурация и оркестрация
из справочника не выполняются. Отчёт относится только к этой зоне.

Найди реальные токены, UI-примитивы и один-два эталонных экрана проекта.
Если UI не затронут — сообщи, что зона неприменима. Если дизайн-системы нет,
не придумывай её. Локализацию проверь через [i18n-sync](../i18n-sync/SKILL.md)
в режиме `--check`: проверка дизайна не разрешает синхронизацию файлов.
