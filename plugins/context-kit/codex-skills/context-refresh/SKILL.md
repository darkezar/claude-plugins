# Обновление AGENTS.md

Приведи существующий `AGENTS.md` в соответствие с проектом. Вызов этого навыка разрешает
аудит и однозначные механические исправления инструкций, без коммита и публикации.

## Аудит

Выполни [context-audit](../context-audit/SKILL.md) из этого пакета и покажи краткий отчёт.
Используй его правила выбора файла и области, включая явно заданный путь, вложенные инструкции
и `AGENTS.override.md`. Если ранее выполненный аудит относится к тому же файлу, перепроверь
его находки по текущему дереву перед изменениями.

Если файла нет, сообщи путь и предложи создать `AGENTS.md` отдельной задачей или через
встроенную команду Codex `/init`. Не вызывай Claude-команду `/context-init` и не создавай файл
вместо обновления. Если цель перекрыта `AGENTS.override.md`, объясни, какой файл действует;
не редактируй переопределение без запроса на него.

## Изменения

- **Механическое.** Исправляй подтверждённые переезды путей, неверные ссылки и команды с
  однозначной заменой без повторного подтверждения. Если замены нет или команда не проверена
  из-за среды, оставь находку открытой; не удаляй правило только потому, что путь исчез.
- **Правило против кода.** Покажи текст правила, противоречащий код и доступную историю.
  Предложи два решения: обновить устаревшее правило либо исправить нарушение в коде.
  Если пользователь уже явно выбрал решение, выполни его в пределах поручения. Иначе спроси
  только о спорном пункте; остальные однозначные правки продолжай. Не подгоняй инвариант
  под текущую реализацию и не исправляй код без отдельного поручения.
- **Сокращение.** Предложи конкретные разделы и причины: пересказ кода, дублирование,
  устаревшие или общие сведения. Сокращай после решения пользователя; уже данное разрешение
  учитывай. Ориентир в 60–100 строк не оправдывает удаление важных ограничений.
- **Добавления.** Предложи короткие формулировки существенных пропусков. Новые инварианты,
  запреты и контракты вноси по решению пользователя, а не выводи их из текущего кода.

Изменяй только выбранные файлы инструкций. Сохраняй несвязанные пользовательские правки,
структуру монорепо и области действия правил. Не синхронизируй `CLAUDE.md` автоматически:
у Claude Code собственные команды плагина. Если выбранный файл — ссылка на другой файл,
покажи фактическую цель и выясни разрешение на неё до записи; не разрывай ссылку.

## Результат

Проверь изменённые пути и команды повторно в необходимом объёме. Покажи diff только выбранных
файлов, например `git diff -- AGENTS.md` из корня репозитория. Для вложенного файла используй
его путь от корня. Если файл не отслеживается git или каталог вне git, покажи сравнение
с сохранённым до правок текстом: пустой `git diff` не доказывает отсутствие изменений.

Отдельно перечисли внесённые исправления, оставшиеся вопросы и непроверенное. Если требуется
решение пользователя, процитируй относящееся к нему правило этого навыка и дай ссылку
на этот `SKILL.md`. Не коммить и не отправляй изменения. Для проверки загрузки обновлённых
инструкций предложи новый запуск Codex, не обещай автоматическое обновление контекста чата.
