# Человеческий язык

Задача — чтобы прочитавший **понял и смог решить**. Не «чтобы звучало проще».

Отсюда два ограничения, которые важнее красоты: **факты не выбрасываются** и **выводы
не смягчаются**. Всё остальное можно переписывать свободно.

## Что делает текст непонятным

Жаргон — только третья причина. Первые две встречаются чаще и вредят сильнее.

**1. Пассив и отглагольные существительные.** Из фразы пропадает тот, кто действует.

> Не производится валидация входных данных → **сервер не проверяет, что прислал клиент**

> Возможна потеря консистентности → **в базе окажутся данные, противоречащие друг другу**

Правило: у каждого утверждения должен быть виновник — кто именно что делает или не делает.

**2. Определение вместо примера.** Определение объясняет, чем вещь является. Человеку нужно,
что она с ним сделает.

> IDOR — это уязвимость, при которой отсутствует проверка принадлежности объекта
> → **поменяв цифру в адресе, человек увидит чужой заказ**

**3. Термин.** Заменяется не синонимом, а описанием действия. «Мемоизация» → не «кэширование
результата», а «повторно не пересчитывать то же самое».

## Когда термин оставить

Всегда оставляй, если слово понадобится в разговоре с другими: в тикете, в коммите, в переписке
с подрядчиком. Убрав его совсем, ты лишишь человека возможности объясниться.

Способ: **термин в скобках, один раз.**

> на каждую строку списка уходит отдельный запрос в базу (это называют «проблемой N+1»)

Дальше в тексте пользуйся им свободно — он уже введён.

## Словарь

Не для подстановки вслепую: подставляй, только если оно верно **в этом** случае.

| Термин | По-человечески |
|---|---|
| N+1 | на каждую строку списка — отдельный запрос в базу |
| Индекс (в БД) | указатель; без него база перебирает все строки подряд |
| Миграция | изменение структуры базы: колонки, таблицы, связи |
| Гонка (race condition) | два запроса пришли одновременно, и оба прошли проверку, которая должна была пропустить один |
| TOCTOU | проверили — а между проверкой и действием всё успело измениться |
| Блокировка (lock) | очередь: второй ждёт, пока первый закончит |
| Идемпотентность | повторный запрос не делает работу второй раз |
| IDOR | подставив чужой номер в адрес, получаешь чужие данные |
| Mass assignment | клиент прислал лишнее поле, и оно молча записалось в базу |
| Инъекция | введённый текст исполняется как команда, а не читается как текст |
| XSS | чужой скрипт исполняется в браузере вашего пользователя |
| Rate limit | ограничение, сколько раз в минуту можно дёргать ручку |
| Soft delete | пометка «удалено» вместо настоящего удаления — данные остаются |
| Регрессия | сломалось то, что раньше работало |
| Рефакторинг | переписали внутри, снаружи должно вести себя так же |
| Покрытие тестами | какая часть кода вообще проверяется автоматически |
| Транзакция | несколько действий, которые применяются целиком или никак |
| Кэш | сохранённый ответ, чтобы не считать заново; главная беда — устаревает |
| Хардкод | значение вписано прямо в код вместо настройки |
| Валидация | проверка, что пришедшие данные вообще годятся |
| Деплой | выкладка новой версии на боевой сервер |
| Откат | возврат на предыдущую версию |
| Дифф | что изменилось: было / стало |
| Мёрж | объединение веток |
| Флаки-тест | тест, который падает через раз без изменений в коде |

## Чего делать нельзя

**Смягчать.** «Критично» остаётся «критично». Мягкая формулировка серьёзной проблемы —
дезинформация, а не забота о читателе. Упрощается язык, а не приговор.

**Выбрасывать конкретику.** Имена файлов, номера строк, числа, условия «когда именно» — это
и есть содержание. Короче текст становится за счёт воды: вводных оборотов, повторов, оговорок
и объяснений очевидного. Если после сокращения нельзя понять, где искать проблему, — сокращено
неправильно.

**Заменять точный термин неточной метафорой.** Неверная аналогия хуже непонятного слова:
непонятное слово можно спросить, а неверную картину в голове — нет.

**Притворяться, что понял.** Не разобрался в пункте — так и напиши: «здесь я не уверен,
что имелось в виду». Уверенный пересказ непонятого — худший из возможных исходов.
