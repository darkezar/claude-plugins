# Изменения

Версия плагина живёт в его `plugins/<имя>/.claude-plugin/plugin.json`. Правишь плагин —
подними версию, иначе у тех, кто ставил с GitHub, `/plugin update` не подхватит изменения.
Локальная установка читает файлы напрямую и работает без этого.

## review-kit

### 0.3.0
- Развилки вместо «оставлено автору»: по каждому неавтоматическому замечанию — проблема,
  конкретный пример как она стреляет, варианты с последствиями и рекомендация. Решает пользователь,
  агент реализует выбранное вместе с тестом.
- Фаза починки: `agent-fixer`, `/apply-fixes`, `i18n-sync`. Ревьюеры остаются read-only.
- Команды тулинга берутся у `tooling-kit`, если он установлен, вместо угадывания.
- Расхождения `CLAUDE.md` с кодом выносятся отдельной строкой в итог отчёта.
- Шаблон PR для багфиксов связан с `/debug`.

### 0.2.0
- Фиксированного набора агентов больше нет: оркестратор классифицирует дифф и решает, кто нужен.
  Запас несимметричный — security и auth по слабому признаку, design и performance по явному.
- Именование и читаемость целиком отданы `simplify` — раньше эти замечания приезжали дважды.
  Обнаружено на боевом прогоне.
- Аргументы `all`, `min`, перечисление агентов через запятую, `--fix`.

### 0.1.0
- Шесть ревьюеров с разведёнными зонами, картриджи стека, базовая ветка по `origin/HEAD`.

## tooling-kit

- Различие `run --rm` и `exec`: первое работает при опущенном окружении, второе требует
  запущенного сервиса.
